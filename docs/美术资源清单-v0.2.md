# 《饿了喵》美术方向与资源清单 v0.2

来源：[PRD v0.2](PRD-v0.2.md) 第 16—21 节。

## 16. 美术方向规范

概念方向：水彩与不透明水粉质感、暖褐细线、低饱和自然色、柔和生活光线。

| 元素 | 设计要求 |
| --- | --- |
| 猫咪 | 四足体态、轮廓清楚，以耳尾和身体动作表达情绪 |
| 装备 | 轻量、贴合猫体，不妨碍肩胛、四肢和尾巴 |
| 配送站 | 木材、帆布、纸张、陶瓷，有使用痕迹但整洁 |
| 食物 | 温暖、有食欲，缩小后仍能辨认 |
| 地图 | 路网清晰，建筑和绿地低对比，任务信息突出 |
| UI | 清楚的导航系统语言，少量纸张、爪印与手写元素 |
| 特效 | 轻量、小范围，避免强闪烁和大量粒子 |

| 用途 | 色值 |
| --- | --- |
| 奶油纸白 | `#F5EBDD` |
| 鼠尾草绿 | `#87977A` |
| 暖橘 | `#D99A63` |
| 陶土红 | `#B86750` |
| 暖褐文字 | `#51463D` |
| 地图建筑灰 | `#D9D8D1` |
| 水系蓝灰 | `#A9C2C6` |

小字号文字不直接使用浅色主色，最终需检查对比度。地图角色以头像定位点呈现；完整形象主要出现在角色页、配送站和故事中。

## 17. 角色设计说明

![猫咪配送员角色设定](../assets/concept-art/characters.png)

| 角色 | 识别轮廓 | 主配色与配件 | 动作重点 |
| --- | --- | --- | --- |
| 吨吨 | 圆脸、结实身躯、厚尾巴 | 橘白毛色、绿色双侧包 | 闻味、犹豫、满足地趴下 |
| 闪电 | 修长身形、向前的耳朵 | 狸花纹、赭黄包、珊瑚色领巾 | 碎步、急停、回头 |
| 老板 | 稳定坐姿、清晰三花色块 | 米白与黑橘、绿色小方巾 | 整理装备、眯眼、转身 |
| 夜班 | 黑色轮廓、琥珀眼睛 | 深蓝雨披、反光细边 | 谨慎观察、安静行走 |

生产稿需统一正、侧、背面花纹和装备结构。概念图中的姿态属于表达探索，正式动作以自然猫体态为准。夜班为 P1 展示角色。

## 21. 美术交付与验收

交付包包含源文件、导出图、预览图、资源说明与授权记录。建议命名为 `类别_对象_状态_版本`，例如 `ch_dundun_idle_v01`、`ui_ordercard_selected_v01`。

验收重点：

- 角色跨视图花纹一致，装备挂点不漂移。
- 三只猫缩到头像尺寸后仍可辨认。
- 雨披和包具在动作中不明显穿插。
- 地图标记在浅色、绿地、水系上均可读。
- UI 包含正常、选中、禁用、空数据、加载失败状态。
- 透明图片无白边，背景与可交互物体分层。
- 字体、纹理、地图数据和其他素材具备对应使用权限。
- 生成概念图里的英文、伪文字和示意地图不直接进入正式产品。
