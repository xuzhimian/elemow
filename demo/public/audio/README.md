# 背景音乐：街角的慢时光

原创程序编曲，2026-10-20。没有使用第三方歌曲、采样或录音。

- 时长：80 秒（24 小节，72 BPM，4/4 拍），立体声 MP3。
- 风格：日式治愈氛围；柔和合成钢琴、拨弦与温暖长音，D 大调与五声音阶旋律。
- 文件：`slow-corner.mp3`，128kbps；离线渲染，游戏不需要实时合成整首音乐。
- 源乐谱与生成器：`demo/tools/render-music.py`。安装 Python numpy 与 ffmpeg 后，在 demo 目录运行 `python tools/render-music.py` 可重现。
- 首次用户交互后开始循环；音乐与操作音效分别开关，音乐可调音量。设置单独保存在本地，不改变游戏存档。
- 切后台暂停，返回后尝试继续。浏览器阻止播放时，显示提示并可再次点击恢复；没有绕过浏览器自动播放限制。
