# 随机事件动画 · 街区小片刻

制作日期：2026-10-20。四只配送猫各六组事件关键帧，共 96 个绘制帧，配套 24 个可独立播放的动画 WebP。

## 素材与排列

- `dundun-atlas.webp`、`shandian-atlas.webp`、`laoban-atlas.webp`、`mianmian-atlas.webp`：各 1024×1536，4 列 ×6 行，256px 方形帧。
- 六行依次为 `bird`、`box`、`fish`、`touch`、`stay`、`rain`。
- `角色-事件.webp`：256px 动画预览，四帧，末帧稍作停留，可直接保存或查看。
- `manifest.json`：原生成图标识、行边界和输出网格规格。生成图非精确网格，已按实际行边界规整，避免运行时截断脚掌或混入相邻行。
- [打开预览页](index.html)：运行 Demo 后访问 `/art/events/index.html`；子目录部署时加上对应站点前缀。

## 角色差异

| 角色 | 动作气质 | 游戏内单次时长 |
| --- | --- | --- |
| 吨吨 | 圆润、慢吞吞，纸箱与鱼香格外认真 | 4.4 秒 |
| 闪电 | 好奇轻快，抬爪和转头更利落 | 3.6 秒 |
| 老板 | 克制、从容，坐姿整齐 | 4.8 秒 |
| 绵绵 | 柔和亲近，蓬松尾巴与慢眨眼 | 5.2 秒 |

动画使用参考既有角色立绘生成的独立动作关键帧，保持日式治愈水彩画风；由 Canvas 播放、短过渡与轻微姿态变化连接。它不是连续视频或完整骨骼动画。

## 事件接入

- 观鸟、纸箱、鱼香、摸猫、陪伴按 `event.catId` 播放对应角色；雨天展示所有已解锁猫咪，并分别使用它们的避雨动画与节奏。
- 保留现有规则：鱼香通常只触发吨吨，陪伴通常只触发绵绵，摸猫仍遵循原触发条件。完整 24 组素材用于覆盖角色与事件的组合，不为展示素材而改变派单数值或触发概率。
- 自动播放一次后停留末帧，可暂停／继续／重播。处理选项始终可用，关闭事件立即释放播放器；动画不推进配送计时。
- 系统减少动态效果时默认停留首帧，允许玩家主动播放；切后台暂停，回前台只恢复此前正在播放的动画。
- 加载失败显示静态提示，玩家仍可正常处理事件。未完成的加载回调不会重启已销毁的播放器。
